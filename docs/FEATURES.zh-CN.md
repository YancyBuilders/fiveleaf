# 功能手册

简体中文 · [English](FEATURES.md)

<a name="explorer"></a>

## 资源管理器

文件树按需加载并随磁盘变化更新，Git 忽略的文件以较淡的颜色显示。可以在这里新建、重命名、移入废纸篓，或在文件管理器中显示文件。在 Git 工作树里，发生变更的文件名带颜色和字母标记（修改 M、新增 A、删除 D、未跟踪 U、冲突 C）。含有变更的文件夹带圆点。指针停在侧栏上时，顶部的文件夹行会显示新建文件、新建文件夹、刷新和折叠文件夹按钮。

单击文件下方的空白处或按 Escape，可以取消选中的文件或文件夹。此时新建文件会放在工作区根目录。右键单击空白处可打开工作区菜单，里面有新建文件、新建文件夹、在 Finder 中显示、在终端中打开和粘贴。

要比较两个本地文件，右键单击第一个文件并选择 **标记为比较基准**。再右键单击第二个文件，选择 **与标记的文件比较**。标记的文件显示在左侧，下次比较时仍可使用它。

**查看 → 压缩文件夹** 会把每一层只有一个子文件夹的目录链显示在同一行，例如 `src/main/java/com/example`。这一行的操作作用于末级文件夹。

<a name="editor"></a>

## 编辑器

编辑区有标签页、行号、光标所在行高亮和 Chroma 语法高亮。磁盘上的文件有变更时，编辑器会重新加载。当前文件有未保存的改动时，会保留编辑中的内容。光标在 120 毫秒内滑到附近位置，身后的连续拖尾会拉长和弯曲。鼠标单击、键盘导航和选区移动也有滑动效果，距离较远时耗时 220 毫秒。源码和实时预览都支持这些动效，包括 Vim 和 Helix 中带计数的移动以及单词、行和文档跳转。选区会立即更新，拖动时光标和拖尾朝选区终点移动。光标停下后，较亮的拖尾会收拢。双击、滚动、缩放、失去焦点或启用系统的减少动态效果设置，都会立即清除拖尾。关闭 **设置 → 编辑器 → 平滑光标** 可同时停用滑动和拖尾。

在 **查看 → 行号** 或 **设置 → 编辑器** 中可选择绝对行号或相对行号。相对行号显示各行与光标所在行的距离，光标所在行仍用绝对行号。该选择对所有窗口生效。

从资源管理器或搜索结果打开文件时，会先用一个名称为斜体的预览标签页显示。下一个文件会复用这个标签页，便于连续浏览。编辑文件、双击文件或标签页、按 Enter 或拖到另一栏，都能将它作为普通标签页保留。文件已在某个标签页中打开时，会直接切换到那里。每一栏都有自己的预览标签页，重启应用后仍以预览标签页恢复。从源代码管理打开提交时，也会使用同一个预览标签页。

**文件 → 比较两个文件…** 可在差异标签页中打开两个本地文件，文件也可以位于 Git 仓库之外。在选择器中选好两个文件后，点击变更块的 **接受左侧** 或 **接受右侧** 箭头，可将该块复制到另一份文件。可以撤销这次编辑，也可以从对应的文件标签页保存变更。

按 `⇧⌘T` 可在原来的栏和位置重新打开最近关闭的标签页，同时恢复光标和滚动位置。再按一次可重新打开前一个。关闭终端会结束会话，终端标签页不会加入此历史记录。打开或关闭文件夹会清空已关闭标签页的记录。

在标签页的任意位置按鼠标中键可直接关闭它，当前阅读的文件会留在原位。

<a name="word-wrap"></a>

### 自动换行

长行默认可以横向滚动。**查看 → 自动换行** 会在编辑区边缘折行。`⌥Z` 只切换当前标签页的换行状态，状态会保留到再次更改设置。

<a name="auto-save"></a>

### 自动保存

修改后的文件会在以下时机保存。

- 距离上次编辑一秒后。
- 所在栏切换到另一个标签页，或键盘焦点切换到另一栏时。
- 窗口失去焦点时。

关闭已修改的文件时会直接保存。未命名的文件可用 `⌘S` 保存。可从 **文件 → 自动保存** 关闭这一行为。

<a name="editing"></a>

### 编辑操作

- `Tab` 和 `⇧Tab` 缩进和减少缩进，沿用当前文件的制表符或空格。
- `Enter` 保留缩进。左括号之后换行会再缩进一级。
- 括号与引号会自动配对，也可包裹选区。再次输入右括号或结束引号时，光标会越过已有的字符。
- 编辑命令可注释、移动、复制或删除行，也可在当前行的上方或下方插入一行。
- 剪切（`⌘X`）会剪切选区。光标处没有选区时剪切整行。这些操作均可一步撤销。
- `Home` 移到当前行的第一个非空白字符。
- 状态栏显示当前文件的缩进和换行符格式，点击可以更改。

<a name="vim-mode"></a>

### Vim 模式

从 **查看 → Vim 模式** 启用 Vim 键位。各标签页独立记录模式，并在状态栏显示。初始为普通模式，光标呈方块。

- **移动命令**包括 `h j k l`、`w b e ge`、`W B E gE`、`0 ^ $ g_`、`gg G`、`H M L`、`f F t T`（可用 `;` 和 `,` 继续查找）、`%`、`{ }`、`[( [{ ]) ]}`、`Enter` 和 `-`。方向键、`Home` 和 `End` 也可移动。上述移动前可以加计数。
- **操作符**包括 `d c y`、`> <`、注释用的 `gc`，以及更改大小写的 `g~ gu gU`。可与移动命令或文本对象配合。文本对象包括 `iw aw iW aW`、`i" a"` 及其他引号、`i( a(`、`i[`、`i{`、`i<`、用于标签的 `it at` 和用于段落的 `ip ap`。重复输入操作符会按行操作，例如 `dd`。
- **编辑命令**包括 `x X D C Y s S r J gJ ~ p P gp gP o O`。`i a I A gi` 用于插入，可以在前面加计数，例如 `3ix`。`u` 和 `⌃R` 分别用于撤销和重做，`.` 重复上一次修改，`⌃A` 和 `⌃X` 增加和减少数字。`⌃D ⌃U ⌃F ⌃B` 滚动半屏或整屏，`⌃E ⌃Y` 滚动一行，`zz zt zb` 将光标所在行分别放到视图的中间、顶部和底部。
- **寄存器**用命令前的 `"a` 到 `"z` 指定复制、删除和粘贴的位置，`"A` 追加到对应寄存器。`"0` 记录上次复制，`"1` 到 `"9` 记录最近删除的行，`"-` 记录上次小范围删除，`"_` 丢弃内容，`".` 记录上次插入的文本，`":` 记录上次命令，`"/` 记录上次搜索。`:reg` 可查看寄存器。
- **宏**用 `qa` 开始把按键录到寄存器 `a`，状态栏会显示录制状态，按 `q` 停止。`@a` 回放，`3@a` 回放三次，`@@` 回放上次使用的寄存器，`@:` 执行上次命令。移动失败时停止回放，行为与 Vim 一致。
- **标记和跳转**支持用 `ma` 设置标记、`'a` 跳到标记所在行、`` `a `` 跳到标记位置。文本变化时标记随之移动。`''` 回到跳转前的位置。`G`、`%`、搜索和标记等跳转会记录在历史里，`⌃O` 向后、`⌃I`（`Tab`）向前。`:marks` 列出标记。
- **转到定义**使用 `gd`。它和 `F12` 一样，向文档的语言服务器请求光标处名称的定义。
- **可视模式**用 `v` 按字符选择，`V` 按行选择，`gv` 恢复上一次选区。鼠标选区也会进入可视模式。移动命令扩展选区，`o` 交换两端，操作符及 `r`、`J`、`~ u U`、`p` 都可操作选区。
- **Hop 跳转**用 `gs` 为可见单词的开头加标签，`gS` 为各可见行的首个非空白字符加标签。输入标签即可跳转，可视模式下会扩展选区。`:HopWord` 和 `:HopLine` 可打开同样的提示。`:HopChar1` 和 `:HopChar2` 先接收一或两个查找字符，再为可见的匹配项加标签。按 Esc 取消，Backspace 删除上一个查找或标签字符。完成的跳转进入 Vim 跳转历史。Hop 风格的命令是内置功能，无需 Neovim 或 Lua。
- **搜索**用 `/` 或 `?` 在编辑区底部打开输入行。输入时光标移到首个匹配项，所有匹配项加亮，输入行显示匹配数量。按 Return 搜索，Esc 回到先前位置，`↑` 和 `↓` 浏览此前的搜索。`n N` 重复搜索，`* #` 搜索光标下的单词，搜索也可作为移动命令使用，例如 `d/end`。正则表达式沿用 Vim 的写法，包括 `\( \) \| \+ \< \>`，也支持用 `\v` 切换模式。正则表达式包含大写字母或 `\C` 时区分大小写，其他情况忽略大小写。匹配高亮会保留到普通模式下按 Esc，或执行 `:noh`。
- **`:` 命令**支持 `:w`、`:q`、`:wq`、`:x`、`:wa`、`:qa` 和跳到行号，例如 `:42`。`:s/old/new/g` 支持 `%`、`2,10` 或选区范围，替换串可用 `& \1 \n`。另有 `:d`、`:y`、`:j`、`:> :<`、`:sort`（含 `!`、`i`、`n`、`u`）、用于移动和复制行的 `:m` 和 `:t`、粘贴寄存器内容的 `:pu`、对范围内每一行执行按键的 `:normal`、分别对匹配或不匹配的行执行命令的 `:g/pattern/command` 和 `:v`，以及重复上次 `:s` 的 `&` 和 `g&`、`:noh`、`:e file`、`:vs`、`:bn :bp`。`'a` 等标记所在的行也可用作地址。`ZZ` 保存并关闭，`ZQ` 直接关闭。`:g`、多行 `:normal` 和 `:%s` 均可一步撤销。

按 Esc、`⌃[` 或 `⌃C` 退出插入模式。一次修改和紧随其后的输入可一起撤销。复制、删除和粘贴默认使用系统剪贴板，显式指定时使用相应寄存器。整行复制的内容会按整行粘贴。Control 未作为快捷键修饰键时，插入模式中的 `⌃W` 和 `⌃U` 会删除光标前的单词和行。普通模式中的 `⌃R` 执行重做。`⌘` 快捷键在所有模式都照常工作。标点键按美式键盘布局处理。在 Windows 和 Linux 上，普通模式的 `⌃F`、`⌃B`、`⌃R`、`⌃O` 分别保留查找、切换侧栏、打开最近项目和打开的用途，`⌃A` 和 `⌃X` 分别为全选和剪切。可用 `vimCtrlKeys` 启用这些键的 Vim 行为。

<a name="helix-keys"></a>

### Helix 按键

从 **查看 → Helix 按键** 启用，或设置 `"editorMode": "helix"`，即可使用 Helix 的核心键位。每个标签页从普通模式开始，先选中一个字符。状态栏显示 `NORMAL` 或 `INSERT`。

- **移动命令**包括 `h j k l`、`w b e W B E ge`、`0 ^ $`、跳到行首和行尾的 `gh gl`，以及 `gg G`。这些命令前都可加计数。选区随移动经过的字符更新。
- **跳转到单词**用 `gw` 给至少两个字符的可见单词加双字母标签。输入标签可选中整个单词，按 Esc 取消。标签只出现在当前编辑器内，包括实时预览的可见文字。折叠的文字和被渲染内容替代的源码不会加标签。
- **插入与编辑**用 `i a I A o O` 插入。`x d D s c y Y` 用于删除、修改、复制，`p P` 用于粘贴。`r` 用一个字符替换选区，`~` 切换大小写，`> <` 缩进或减少选区所在行的缩进。`u` 和 `U` 分别用于撤销和重做。
- **转到定义**用 `gd` 跳到所选名称的定义，和 `F12` 一样使用文档的语言服务器。
- **其他命令**包括按段落移动的 `{ }`、添加或移除成对符号的 `( ) [ ]`、跳到匹配括号的 `%`，以及打开 Leader 菜单的 `Space`。

当前模式使用单个选区。按 Esc、`⌃[` 或 `⌃C` 离开插入模式后，光标前的字符会被选中，与 Helix 一致。**查看 → Vim 模式** 与 **查看 → Helix 按键** 互斥。旧设置 `"vim": true` 仍会启用 Vim。

命令面板也列出 **HopWord**、**HopLine**、**HopChar1**、**HopChar2** 和 **Helix：跳转到单词（gw）**。可用 `keybindings.json` 为 `go.hopWord`、`go.hopLine`、`go.hopChar1`、`go.hopChar2` 或 `go.helixWord` 绑定自定义快捷键。Hop 命令使用 Vim 模式，Helix 命令使用 Helix 模式。滚动、切换文档或将焦点移出编辑器时会取消正在显示的标签。

<a name="leader-menu"></a>

### Leader 菜单

在 Vim 的普通或可视模式，或 Helix 的普通模式中，按 Space 可在状态栏上方的右下角打开一块快捷键面板。面板列出命令和后续键位，编辑区仍然可见。选择一组命令后，可以按命令旁的键或直接单击。按 Esc 关闭菜单，按 Backspace 或左方向键退回上一级。菜单使用 FiveLeaf 的文件、搜索、代码、标签页、窗口和 Git 命令。

| 按键 | 操作 |
| --- | --- |
| `Space Space` | 快速打开 |
| `Space p` | 命令面板 |
| `Space f` | 文件命令，`f` 快速打开，`s` 保存 |
| `Space s` | 搜索命令，`w` 搜索工作区，`s` 打开符号列表 |
| `Space c` | 代码命令，`d` 转到定义，`h` 显示悬浮信息，`f` 格式化 |
| `Space c l` | 语言服务器状态和操作 |
| `Space b` | 标签页命令，`n` 和 `p` 切换标签页，`d` 关闭标签页 |
| `Space w` | 编辑器分栏 |
| `Space g` | Git 改动、分支和工作树 |

在插入模式、搜索框和终端中，Space 仍输入空格。`f<Space>` 和 `r<Space>` 等 Vim 多键命令也保持原义。自定义快捷键优先于默认的 Leader 键。命令面板也提供 **Leader 菜单…**，可为 `go.leaderMenu` 绑定自定义快捷键。

在这些模式中，`Ctrl-w` 可直接打开窗口菜单，用以下按键操作编辑器分栏。

| `Ctrl-w` 或 `Space w` 后的按键 | 操作 |
| --- | --- |
| `v` | 将当前视图向右拆为新栏 |
| `h` / `l` | 聚焦左侧或右侧一栏，抵达边缘时停止 |
| `w` / `W` | 循环切换到下一栏或上一栏 |
| `q` | 关闭当前栏及其中的标签页，Vim 中也可按 `c` |
| `o` | 仅保留当前栏 |
| `=` | 均分未锁定栏的宽度 |

按后续字母时可以继续按住 Ctrl，例如用 `Ctrl-w Ctrl-w` 循环切换分栏。按 Esc 可取消，按 Backspace 或左方向键可关闭通过 `Ctrl-w` 直接打开的菜单。自定义键位及组合键优先于这组前缀键。处于可接收模式命令的编辑状态时，前缀键优先于继承的关闭标签页快捷键。

关闭分栏时，如有未保存的文档，会提示保存、放弃或取消。最后一栏会保留为空工作区。锁定栏受保护，无法直接关闭。若 **仅保留当前分栏** 会关闭锁定栏，该命令也不可用。要上下分栏，可使用标签栏的分栏选择器或命令面板。窗口菜单没有绑定 `Ctrl-w s`、`j` 或 `k`。

<a name="undo"></a>

### 撤销

每个标签页保留自己的历史记录，包括键盘输入和应用执行的编辑操作。调整缩进、移动行、执行替换和从磁盘重新加载都可以撤销。撤销到上次保存的文本后，标签页会清除未保存标记。

<a name="reading-aids"></a>

### 阅读辅助

- 显示缩进参考线，光标所在块的参考线更亮。
- 给与光标处括号配对的括号加边框。
- 高亮光标处单词的其他出现位置。
- 选区为圆角，显示其中的空格和制表符。焦点移开时，选区以较淡的颜色保留。
- 粘性滚动把当前可见块的起始行固定在顶部，面包屑显示光标所在的块。点击固定行或面包屑可跳转。
- 点击面包屑中的文件夹可展开独立于资源管理器的文件树。可用鼠标，或用方向键和 Enter 展开目录、选取文件，并在当前栏显示。

<a name="git"></a>

### Git

编辑区边栏标记上次提交以来新增、修改或删除的行。右侧的概览条显示全文件的变更、查找结果和光标位置。

点击标记，会在变更下方显示这些行在 HEAD 时的内容。可以就地还原变更（支持撤销），或仅暂存显示的这些行。`⌥F5` 和 `⇧⌥F5` 跳到下一处和上一处变更。**Git** 菜单也提供针对光标处变更的相同命令。

光标停留片刻后，所在行会显示最后修改者、修改时间和提交摘要。可从 **Git → 行内追溯**（Inline Blame）关闭。

**Git → 在远程仓库中打开文件** 在 GitHub、GitLab 或 Bitbucket 上打开文件，并标出光标行或选区行（`#L10-L20`）。链接指向上游分支。分支没有上游时，链接指向当前检出的提交。**Git → 复制永久链接** 复制指向当前检出提交的同类链接。标签页及资源管理器的文件菜单也提供这两个操作，链接指向整个文件。远程仓库按上游、`origin`、第一个远程的顺序选取。

<a name="source-control"></a>

## 源代码管理

侧栏顶部 **资源管理器** 旁的按钮（`⌃⇧G`）切换到当前文件夹的 Git 工作树改动视图，并显示变更数量。文件分为合并更改、已暂存更改、更改和未跟踪文件。

- 列表和树形视图按钮旁的 **打开提交图** 会在编辑器标签页中打开仓库历史。点 **所有分支** 搜索本地或远程分支。选中提交可查看详情，双击或按 `Enter` 可打开其更改。图上的筛选仅作用于当前标签页。
- **抓取** 显示当前分支比上游落后（`↓`）和领先（`↑`）的提交数。点击任一数字只会抓取。**抓取** 旁的下拉菜单可拉取、推送，也可以为尚无上游的分支选择 **发布分支**。
- **切换工作树…** 按文件夹和分支列出各个检出的工作树，当前打开的排在最前。选中一项即可打开对应文件夹。未筛选的列表顶部有 **创建工作树…**，会提示输入新分支名。在搜索框输入新名称时，也可直接选 **创建工作树**。两种方式都会以打开选择器时 HEAD 所在的提交为基准，把新工作树检出到和主工作树同级的 `<folder>.worktrees` 下。输入已有分支名时会指向 **切换分支…**。目录已经不存在时会显示提示并保留记录。
- 单击文件或按 `Enter` 查看更改，焦点会交给差异视图，立即可用 `]` `[`、`.` `,` 等键。Shift 单击或 `Shift+↑`、`Shift+↓` 选中一段文件。`⌘` 单击（Windows 和 Linux 上为 Ctrl 单击）添加或取消一个文件，`⌘A` 全选。选中行上的 Space、暂存、取消暂存、放弃按钮和相应菜单项作用于全部选中文件。在未选中的行上操作时，只作用于该文件。
- 文件行的按钮可以打开文件、放弃更改、暂存或取消暂存。分组标题的按钮对组内的所有文件执行同样的操作。放弃前会提示确认，未跟踪文件会移入废纸篓。
- 在底部输入提交说明，然后按 `⌘↵` 或点输入框右下角的提交按钮。按钮会写明操作：**提交**、**全部提交**（当前没有暂存内容时，FiveLeaf 会先确认是否暂存全部），或 **修改提交**。应用会先保存已修改的文件。摘要超过 50 个字符时会显示长度，超过 72 个字符时会用警告色标出。
- 提交按钮旁的箭头提供 **提交并推送**、**修改上次提交**（会填入上次的说明）和 **撤销上次提交**（撤回提交，保留已暂存的更改并把说明放回输入框）。
- 用侧栏顶部的 **平铺列表** 或 **目录树** 切换各 Git 分组的文件显示方式。
- 标题旁的 **⋯** 菜单提供提交命令、暂存全部、取消暂存全部、放弃全部、抓取、拉取、推送、刷新和 **以树形显示**。树形视图按文件夹列出各组文件，只有一个子文件夹的目录链会合并成一行，例如 `internal/git`。文件夹的按钮会暂存、取消暂存或放弃其中的所有文件。
- **⋯ → 储藏更改…** 会保存当前改动，可附上说明。**储藏更改（含未跟踪文件）…** 也会储藏未跟踪文件。应用会先保存打开的文件，通知上的 **弹出** 按钮可以恢复改动。**储藏** 子菜单列出最近十条，每条都有 **应用**、**弹出**（应用后删除）和 **删除…**（需先确认）。弹出时如果发生冲突，会保留储藏，相关文件显示在合并更改中。
- **Git → 储藏列表…** 可打开所有储藏，显示各自的分支和创建时间，并可按说明或分支搜索。`⏎` 应用选中项，`⌘⏎` 弹出，`⌘⌫` 删除。**Git** 菜单和命令面板也提供储藏命令。
- Git 命令运行时，标题下方会显示移动中的细条。提交后会出现带 **撤销** 按钮的通知，推送或拉取完成后也会通知。
- 工作树干净时会显示提示。如果分支领先于上游，会提供推送选项。落后于上游时会提供拉取选项。
- 当前目录不在仓库内时，会提供 **初始化仓库** 按钮。

<a name="submodules-and-repository-selection"></a>

### 子模块和仓库选择

已初始化的子模块（含嵌套子模块）会作为独立的可折叠区块，显示在一个可连续滚动的源代码管理列表中。滚动时，当前仓库的标题固定在顶部，变更列表在下方滚动。当前变更组（例如已暂存更改或更改）也会连同计数和操作固定在仓库标题下方，直到下一个分组或仓库将它顶走。标题显示仓库名、分支或分离的 HEAD，以及仓库操作。侧栏较窄时，远程操作收进各仓库的 **⋯** 菜单。

有改动的仓库默认展开，干净的仓库默认折叠。展开后可看到其保留的提交草稿和不可用的提交按钮。箭头用于展开或折叠区块，点击仓库名可选中其历史。各仓库独立保留提交草稿、选区和 Git 操作。暂存、取消暂存、放弃和提交均作用于当前区块的仓库。父仓库中的子模块条目区分提交引用变更和子模块内的未提交内容。请先提交子模块内的文件，再到父仓库单独暂存并提交更新后的引用。未初始化的子模块会留在父仓库列表中，直到在应用外完成初始化。

包含多个仓库时，更改列表会占用侧栏到 **仓库** 标题为止。展开 **仓库** 后，可在更改下方浏览分支和远程。两个区块分别滚动。拖动分隔线前，更改区根据内容自动调整高度，最多占视图的一半。工作区会记住分隔线位置。

面板标题和标题栏上的仓库按钮可打开按仓库名称或路径搜索的选择器。**自动** 跟随当前文件、差异或提交图。也可选定仓库，让打开其他文件时继续使用它。**打开提交图** 会在编辑器中打开所选仓库的图。已打开的提交图和差异仍关联各自的仓库。标题栏的仓库按钮在项目名旁，窗口中的工作树和分支控件只在这里显示，并跟随所选仓库。

放弃等操作的确认对话框会标明目标仓库，在自动模式下也是如此。保存到会话中的差异视图，其仓库路径相对于工作区。发现子模块时会跳过没有 `.gitmodules` 的仓库，并在 Git 元数据或 `.gitmodules` 发生变化时刷新。应用不会定时遍历索引。打开含子模块的工作树时行为相同，其他工作树仍会单独打开。

<a name="commits"></a>

### 提交

编辑器中的 **提交图** 显示所有分支的最新 50 条提交，带有彩色合并轨道以及分支和标签标记。**显示更多提交** 会加载接下来的 50 条。在当前标签页选择分支筛选器，可以跟踪本地或远程分支的历史，当前检出状态不会改变。

选中一行可查看提交说明、作者、日期和短哈希。双击、按 `Enter` 或选择 **打开更改** 可在单独的标签页打开该提交的差异。顶部显示提交说明、作者、日期、哈希、分支和标签，下方像 **更改** 标签页一样列出相对于第一个父提交变更的文件。差异工具栏的按钮和 **Git → 显示提交的文件** 均可打开右侧面板。此面板默认隐藏，文件会按照 **以树形显示** 的设置分文件夹或按路径排列。点击或用方向键选中文件，可滚动差异到对应位置。滚动差异时，顶部文件会在面板中选中。拖动面板边缘可加宽。再次点击按钮或菜单项，可在所有提交标签页中隐藏该面板。

提交菜单可以检出该提交（有对应分支时切换分支，否则经确认后分离 HEAD），在此处创建分支或标签，复制哈希、提交说明或分支、标签名。对 HEAD 上的提交还可以执行撤销。

<a name="diffs"></a>

### 差异视图

所有发生变更的文件都显示在同一个 **更改** 标签页，顺序与源代码管理一致。已暂存更改排在前面，对比 HEAD 和索引。其余更改对比索引和工作树。每个文件上方有标题，显示路径和新增、删除的行数。点击源代码管理中的文件，标签页就会滚动到相应位置。资源管理器、标签页菜单或 **Git** 菜单的 **打开更改** 也可定位到文件。滚动时，源代码管理会选中正在阅读的文件。编辑文件时，差异会随之更新。

各标题先显示文件名，再显示目录和 Git 状态。重命名的文件也会显示旧路径。右侧数字表示新增或删除的行数，省略为零的项。点击标题可折叠文件，变更超过 2,000 行的文件默认折叠。将指针移到标题上或选中标题，可以看到打开文件、暂存或取消暂存、放弃更改的按钮。文件会在接近视区时读取，因此长列表也能立即打开。

工具栏的 **全部折叠** 折叠当前差异标签页中的所有文件，也适用于提交差异。全部折叠后，按钮变为 **全部展开**。**Git** 菜单也提供这两个操作。macOS 上用 `⌥⌘[` 折叠，用 `⌥⌘]` 展开。可在 **设置 → 键盘快捷方式** 为 `git.collapseAllFiles` 和 `git.expandAllFiles` 指定键位，Windows 和 Linux 上这两项默认没有键位。折叠时当前文件标题会留在视区，展开后仍按需读取文件。

每个改动块前后只显示三行未改动的上下文。其余行折成一条写有隐藏行数的提示，点击可展开。每个改动块开头有与 Git 一致的 `@@` 标题，标出行号和所在的代码块。通过 **更多变更操作 → 显示完整文件** 可查看所有行。

指针移到改动块，或选中其中一行时，块标题会提供单独暂存、取消暂存或放弃该块的操作。FiveLeaf 会先重新读取索引和文件，使操作基于当前内容。放弃对已打开文件的更改可作为一步编辑撤销。放弃未打开文件中的更改时会先确认。滚动文件时，带操作按钮的标题固定在视区顶部，点击可折叠文件。

删除行和新增行可以共用一栏和一列行号，也可以并排显示，同一改动的行左右相对。并排时，中间的连接带将左右侧的同一改动连起来。两边行数不同时，连接带会弯曲，其上也会显示操作箭头。指针移到箭头上时会突出显示受影响的行。**更多变更操作 → 布局** 可选择并排、单栏或自动。默认是自动，每侧可以容纳至少 80 列时使用并排布局。行内变更的字词以颜色突出，左侧条在当前改动块旁最亮。长行的折行方式和编辑器一致：**自动换行** 作用于所有标签页，`⌥Z` 或 **更多变更操作 → 切换自动换行** 只作用于当前标签页。

双击某行可打开文件并跳到该行。导航箭头在各处改动之间移动。窄分栏里箭头会移入 **更多变更操作**，折叠按钮仍在工具栏。状态栏显示当前改动的序号、总数及新增、删除的行数。到达文件首处或末处时会提示，再按同方向会跳到下一文件的首处或上一文件的末处。`diffCrossFiles` 可设置为直接跨文件，或只在当前文件内导航。到达第一个或最后一个文件时会提示并停止。差异视图有焦点时，可像分页阅读器一样使用这些键。

<a name="review-comments"></a>

### 审阅评论

要从普通文件收集代码交给 Agent，可在 **设置** 中启用 `"editorAgentContext": true`，该选项默认关闭。指针移到某行后点击 **+**，或先选中多行，即可打开审阅所用的同一种评论卡片。写评论时，源码会在这些行下面为卡片留出空间。保存或取消后回到源码编辑。用 `⌘Enter` 保存，或按 Escape 取消。评论留空并选择 **添加到智能体** 时，只收集代码。可跨文件收集片段，再用编辑器上方的 **发送 N 个条目**，把片段和审阅评论一起粘贴到上次使用的终端，应用不会替你按 Enter。点击 **…** 可查看已收集的条目，进行跳转、编辑或移除。无打开的终端时会复制到剪贴板并保留条目。重启应用或关闭该设置后，待发送条目仍会保留。

审阅 Agent 的更改后，可以一次性粘贴审阅意见。在差异视图中选中行并按 `c`，或点击指针悬停行旁的 **+**，也可在文件中选好行后按 `⇧⌘M`（**添加审阅评论**）。输入意见后用 `⌘Enter` 保存，Escape 放弃。在差异视图中，评论显示在对应行下方，带编辑和删除按钮，行号旁有范围标记。在文件里也会标记这些行，评论显示在最后一行之后。点击它，或在这些行上再次运行命令，即可编辑。滚动条会标记各条评论的位置。并排视图中，评论显示在所属一侧的行下方。编辑时用 **删除** 可删掉这条评论。删除一条或清空所有评论后，通知提供 **撤销**。提交差异也支持评论。状态栏显示评论数，并按文件提供跳转菜单。差异视图里用 `n` 跳到下一条，`N` 跳到上一条。**转到下一条审阅评论** 和 **转到上一条审阅评论** 可从任何位置按文件和行号顺序跳转。跳向对已删除行、暂存行或提交中的行所作的评论时，会在差异视图显示它。

从差异工具栏及其菜单、**Git** 菜单或命令面板执行 **将审阅条目发送到终端**，会把所有评论粘贴到上次使用的终端，然后清除条目。应用不会替你按 Enter，可以在交给 Agent 前补充内容。**复制审阅条目** 会复制相同内容。每条先写行所在的相对路径和行号，然后显示对应的代码（在差异视图创建时则为差异），最后附上评论。有多条时会编号。

评论随文件中的对应行移动。若这些行已从文件中移除，评论会标记为过时并引用原来的行。尚未发送的评论会保留在文件夹的会话中，下次启动时可继续查看。

提交菜单也提供 **创建补丁…**、**复制更改（补丁）**，支持二进制变更和根提交。**比较 HEAD 与此处** 和 **比较此处与 HEAD** 按对应方向打开两者之间的差异，布局沿用差异视图的设置。先选 **选择以进行比较**，再选 **与已选项比较**，可对比同一仓库的两次提交。比较卡片会列出两次提交，点击标识即可复制哈希。比较标签页会随会话恢复。**在远程仓库中打开提交** 支持 GitHub、GitLab 和 Bitbucket，优先使用能唯一确定远程的提交标记，其次使用当前上游、`origin` 或第一个远程。

<a name="branches-and-remotes"></a>

### 分支和远程

源代码管理的 **仓库** 面板位于变更列表下方，初始折叠。它会记住展开状态和选中的标签页。**分支** 优先显示当前分支，其他分支按最新提交排序，每项显示上游和领先、落后的提交数。展开分支可查看历史以及未拉取或未推送的提交。**加载更多** 可再读取一页。**远程** 显示配置过的远程及其指向。展开可读到抓取和推送 URL 以及远程分支。面板打开时加载数据，分支展开时加载其历史。

分支行提供检出和拉取。远程分支的 **抓取远程仓库** 会抓取整个远程。上下文菜单支持新建、重命名、删除、合并和变基分支，也支持添加远程、编辑 URL、移除远程、抓取和清理远程引用。未合并的分支无法用删除命令移除。**刷新** 会重新读取本地引用，**抓取** 会连接远程。

分支在 GitHub 上有拉取请求时，源代码管理中的分支旁和状态栏都会显示请求的编号、检查结果和审阅状态。点击可在标签页中打开其差异，右键可选择 **在 GitHub 上打开**。信息由仓库所在机器上的 `gh` CLI 提供，远程 SSH 项目使用远端的 `gh`。要显示这些信息，需要安装 `gh` 并登录。窗口显示时每分钟重新查询一次，检查运行期间每 30 秒查询一次。

若某条历史提交是一个开放拉取请求的头提交，会在分支和标签之前显示 `#123`。草稿请求的编号颜色较淡。点击编号可在标签页打开差异，右键可选择 **在 GitHub 上打开**。拉取请求同样通过 `gh` 获取。历史加载后在后台查询，引用变化时和每两分钟再次查询。历史显示无需等待这些数据。若缺少 `gh` 或未登录，对应提交行不显示拉取请求。

**Git → 打开拉取请求…** 也出现在源代码管理的 **⋯** 菜单中。它列出开放的拉取请求，当前分支的请求排在最前。可按编号、标题、作者或分支搜索。直接输入任意编号可打开该请求，无论其当前状态。标签页和 GitHub 一样显示头分支从基分支分出的位置到头提交之间的差异。可按常规差异设置使用行内或并排布局。上方卡片显示状态、分支及 **在 GitHub 上打开**。FiveLeaf 会从拉取请求所属仓库的远程抓取尚无的提交到 `refs/fiveleaf/pull/<number>/head` 和 `…/base`，以便应用重启后恢复标签页。来自派生仓库的请求可以直接打开，无需添加其远程。各文件的 **已查看** 复选框会同步标记到 GitHub 并折叠文件。标签页打开时，已查看的文件默认折叠，卡片会统计数量。有比当前标签页更新的提交时，卡片会提供 **重新加载**。

**Git → 显示拉取请求检查…** 列出分支对应请求的检查，失败项排在最前。也可用标记的右键菜单、源代码管理的 **⋯** 菜单中的 **显示检查…**，或点击标记上的检查图标。检查运行期间每 30 秒重新读取，可输入文字搜索。失败的 GitHub Actions 作业提供 **发送到终端**（`⏎`），将日志的最后 3,000 行去掉颜色和时间戳，像 **将审阅条目发送到终端** 一样粘贴到上次使用的终端，应用不会代按 Enter。没有终端时复制到剪贴板。还可以 **复制日志**、**重新运行**（`⌘⏎`）该作业或 **在 GitHub 上打开**。其他系统的检查只提供在 GitHub 打开的操作。

源代码管理顶栏右侧显示 **抓取**。抓取菜单提供拉取、推送，以及为没有上游的分支执行发布。切换分支前会先保存已打开的文件。

点击标题栏的分支或用 **Git → 切换分支…** 可打开分支选择器。当前检出的分支排在最前，其次是本地分支，再是远程分支，各组按最后提交时间由近到远排列。同名的本地和远程分支分别列出。每条显示最近提交的作者、相对时间和摘要。可按名称查找，也可输入新名称，从当前检出的分支创建新分支。未筛选的列表顶部的 **创建分支…** 会打开输入名称的提示。有匹配项时，按 Enter 切换到第一个匹配项，无匹配项时按输入的名称创建分支。选择远程分支会检出一个跟踪它的本地分支。源代码管理和 **Git** 菜单也提供抓取、拉取和推送。

拉取只允许快进。首次推送会设置上游。FiveLeaf 中的 Git 使用 SSH agent 和凭据助手处理认证。认证失败时，错误会提示先在终端中执行一次该命令。

<a name="image-viewer"></a>

## 图像查看器

PNG、JPEG、GIF、WebP 和 BMP 文件在图像查看器中打开。图像默认适应视区，背景为棋盘格。

- 按住 `⌘`（macOS）或 `Ctrl`（Windows 和 Linux）滚动可缩放图像，也可在命令面板中使用 **放大图片** 或 **缩小图片**。
- 点状态栏的缩放百分比，或运行 **图片适应视图**，可回到适应大小。
- `⌘=`、`⌘-`、`⌘0`（macOS）或 `Ctrl+=`、`Ctrl+-`、`Ctrl+0`（Windows 和 Linux）缩放或重置整个窗口，包括侧栏。
- 双击在适应大小和实际大小之间切换。
- 图像大于视区时，可以拖动或滚动查看其他部分。
- 文件变化后，图像会重新加载。

SVG 以文本形式打开。按 `⇧⌘V` 或点击面包屑末尾的按钮，可显示随输入更新的图像。

Markdown（`.md`、`.markdown` 和 `.mdx`）默认以可编辑的实时预览打开。点击文件路径旁的 **源代码** 查看原始 Markdown，按钮会变为 **预览**，再次点击可返回。`⌥⌘V` 也能切换当前标签页的显示方式。用 **查看 → Markdown 打开方式** 设置新打开文件的默认视图。两种视图共享文本、选区和撤销历史。

标题、强调、链接和任务复选框会在输入时保留排版。拖动或 `Shift` 单击可以选择排版后的文本。用 `⌘1` 到 `⌘6` 更改标题级别，`⌘0` 将标题改为段落。Windows 和 Linux 上用 `Ctrl` 代替 `⌘`。

在 **插入表格** 中向右选择列数，向下选择行数。单击，或拖动后松开，就能插入高亮的矩形。也可用方向键和 `Enter`。网格提供 10 列、8 行，数字输入框支持行列各最多 100。行数包含表头。

点击单元格即可就地编辑。编辑时，打开文件路径旁的 **表格**，或右键单击单元格，可在上方或下方插行、在左右插列，也可删除当前行或列。删除表头会将首个正文行提升为表头。只剩一行或一列时，菜单会提供 **删除表格**。`Tab` 横向移动，`Enter` 向下移动一行。按住 `Shift` 使用这两个键可反向移动。表格中也可保存、撤销和重做。改变一行或一列可一步撤销。

从代码块的标题中选择语言，可为其中的多行字符串、注释和其他内容添加高亮。**其他语言…** 接受语法高亮器支持的名称。选择 **纯文本** 可清除高亮。

Mermaid 流程图用琥珀色表示判断，连线及其标签用蓝灰色。一般流程中，浅色主题用蓝色、青色和鼠尾草绿区分入口路径，公共步骤用沙色。深色主题用蓝色、青色和玫瑰色区分入口路径并为文字配色，公共步骤用石墨色背景。这类流程采用分层布局、直角连线和空心箭头。导出的图像和 SVG 沿用当前主题的颜色。点击渲染后的图表或独立公式即可编辑定义，将光标移出后可以查看结果。

右键单击文本可撤销、重做、复制、粘贴和设置 Markdown 格式。标题、粗体、斜体、删除线和行内代码会为选区设置相应格式。**段落** 会更改所在块的类型。链接、图像、代码块、表格、列表、任务和引用可以就地插入或切换。选择同一行内的文本即可应用行内格式，也可以在没有选区时插入标记并直接在标记中输入。插入链接和图像时会选中目标地址，方便立即输入。**编辑 → Markdown** 和命令面板也提供这些操作，可在 **设置 → 键盘快捷方式** 为它们分配按键。Vim 和 Helix 的编辑模式仍可正常使用。

编辑 Markdown 时，`⌘B` 为粗体，`⌘I` 为斜体，`⌘E` 为行内代码，`⌘K` 为链接。按住 `Shift` 时，`⌘X` 为删除线，`⌘K` 为代码块，`⌘L` 为图像。Windows 和 Linux 上用 `Ctrl` 代替 `⌘`。自定义快捷键优先。

在有序列表中按 `Enter` 可插入一项，下方连续项目的编号随之递增。刻意重新起号的项目保持原编号。在列表项文本的开头按 `Backspace`，会移除列表标记和任务复选框，或移除最内层的引用标记。各次编辑均可一步撤销。

用 `⌘\` 拆分后，可并排查看同一份文档的两种视图。一栏的文本变更会同步到另一栏，各栏独立保留视图模式和阅读位置。状态栏统计源码中的字词数和预计阅读分钟数。

实时预览会通过 HTTP 或 HTTPS 自动请求远程图像。加载时显示占位卡片，图像无法显示时使用替代文本。以 `/` 开头的路径像在 GitHub 上一样，从文件所属 Git 仓库的根目录解析。无仓库时从工作区根目录解析。HTML 注释和文件头元数据会隐藏，其余 HTML 按文本显示。

<a name="columns"></a>

## 分栏

点击标签栏末端的 **向右拆分**，可在当前栏右侧开一栏。将指针停在同一按钮上，可选择向左、向右、向上或向下。各栏有自己的标签页，并可再次拆分。拖动分隔线可以调整大小，会话恢复时也会恢复布局。同一个文件可以同时显示在多个栏中，共享文本和撤销历史，各自保留光标与滚动位置。可以沿标签栏拖动标签页，也可以拖入另一栏，或拖到栏边缘新增一栏。

在标签页菜单中用 **锁定栏** 为终端保留一栏，也可从终端标签页或终端面板的菜单中选择 **移到锁定的右侧栏**，一次移动运行中的终端。标签栏的锁图标可以解锁。从资源管理器、搜索、快速打开或源代码管理打开的文件、图像和差异，以及通过 **在编辑器区域新建终端** 打开的终端，会进入键盘焦点所在的未锁定栏。如果键盘焦点在锁定栏，则进入上次使用的未锁定栏。直接把标签页或文件拖进锁定栏，仍可放在那里。关闭文件时，会在锁定栏旁保留至少一个未锁定栏，并保持锁定栏宽度。`⌘W` 可关闭多余的空栏。最后一个终端退出后，锁定栏仍保留，并提供 **新建终端**。各项目的会话会恢复锁定状态、宽度和最后使用的文件栏。命令面板还提供可绑定快捷键的 **切换栏锁定** 和 **将终端移到锁定的右侧栏**。

从 Finder 拖进来的文件会在落点打开。拖到栏内时在当前显示的标签页之后打开，拖到标签栏时按标记的位置打开，拖到栏边缘时在该处新建一栏。放在其他位置（例如资源管理器）时，会在文件工作区的未锁定栏中打开。拖入文件夹和用 `ff <dir>` 打开的效果相同。在 macOS 上，将文件或文件夹放到 FiveLeaf 的程序坞图标上，与用 `ff <path>` 打开的效果相同。

从资源管理器、源代码管理的更改列表或搜索结果拖出的文件也按同样的规则打开。拖入一条搜索结果会打开文件并选中匹配内容。

<a name="terminal"></a>

## 终端

**查看 → 任务** 可在可复用的终端中运行已保存的命令，包括内置的 `lazygit` 和 `yazi`。macOS 上用 `⌥⌘T` 打开任务选择器，其他系统用 `Ctrl+Shift+B`。配置详见 [任务](TASKS.zh-CN.md)。

Ghostty 终端模拟器（libghostty-vt）可以放在面板或分栏标签页中。默认面板位于编辑器下方。可以从 **查看 → 面板位置**、命令面板的 **将面板移到左侧**、**将面板移到右侧** 和 **将面板移到底部**、`keybindings.json` 的 `workbench.action.positionPanelLeft` 等相关命令，或面板标题菜单里的 **面板位置**，把面板移到窗口边缘。面板和侧栏位于同侧时，面板更靠外，拖动内侧边缘可以调整大小。终端按钮在窗口底部，可通过右键菜单单独选择按钮的位置。工作区窗口里的所有终端共用一个位置。**最大化面板** 会将所有终端移到编辑器标签页，并保持所选终端的焦点。点击终端标签页右下角的 **还原面板**，或将标签页拖到状态栏的终端按钮，可停靠回原来的位置和大小。其他窗口不受影响。

用 **新建终端**（`+`）打开另一个终端。**向右拆分** 会在所选终端旁打开独立的 shell。悬停于拆分按钮可选择左右或上下，拖动分隔线可调整大小。停靠的终端在面板内部拆分，编辑器标签页中的终端会拆分工作区分栏。

**关闭终端**（×）只结束选中的会话。关闭最后一个终端会关闭面板。如果只是想隐藏面板并让会话继续运行，可用 **切换终端**。新终端和窗口内已有终端放在一起。**查看 → 新建终端在编辑器区域打开**（`settings.json` 中的 `terminalLocation`）决定首个终端的位置。终端颜色跟随主题。本地项目运行本地 shell，远程文件夹通过 SSH 运行终端。退出 FiveLeaf 会关闭终端，恢复终端标签页时会启动新的 shell。将文件拖入终端会按 shell 的规则转义并输入文件路径。剪贴板上只有图像时，`⌘V` 会像 VS Code 终端一样发送空的括号粘贴序列，以便 Claude Code 粘贴截图。选中文本时会自动复制，与 Ghostty 和 iTerm2 一样。拖动、双击选词、三击选行、在接管鼠标的程序中按住 Shift 拖动或执行全选，均可复制。`terminalCopyOnSelect` 可以关闭这一行为。

在本地终端按住 Command 单击路径（Linux 和 Windows 上按住 Control），可在 FiveLeaf 中打开文件，包括 Git 忽略的文件。应用识别使用正斜杠的路径，例如 `/absolute/path`、`~/path`、`./path`、`../path` 或包含斜杠的相对路径。文件名可带 `:line` 或 `:line:column` 后缀，打开时光标会定位到对应位置。相对路径基于 shell 报告的目录，shell 未报告时使用终端的启动目录。暂不识别 Windows 盘符和反斜杠路径。按住 Command（其他系统上为 Control）并将指针移到可识别路径上时，路径会出现下划线，指针变为手形。

终端中的 `⌘F`（Linux 和 Windows 为 `Ctrl+F`）会在终端上方打开查找栏，搜索屏幕及滚动历史，忽略 ASCII 字母大小写，并随输出更新高亮。Return 或上方向键移到上一个匹配项（更早的输出），Shift+Return 或下方向键移到下一个。`⌘G` 和 `⇧⌘G` 也提供相同操作。按 Escape 关闭查找栏，将键盘焦点还给终端。

在 Windows 和 Linux 上，Ctrl 组合键一般交给 shell 编辑当前行。工作台的快速打开、命令面板、查找、终端和侧栏切换、下一个和上一个标签页、Alt+1 至 Alt+9 与缩放快捷键仍有效。带 Ctrl+Shift 的工作台快捷键和功能键快捷键也仍有效。Ctrl+Shift+C 和 Ctrl+Shift+V 留给终端复制与粘贴。

<a name="sessions"></a>

## Agent 会话

侧栏的 **Agent 会话**（也可用 `view.sessions` 打开）按最近使用时间列出本机编码 Agent 的会话。Claude Code 的记录来自 `~/.claude`、各 `~/.claude-*` 目录、`CLAUDE_CONFIG_DIR` 和 `agentSessionsClaudeDirs` 所列目录，也会读取 Qoder、Codex 和 Grok 的会话。列表按今天、昨天、过去 7 天和更早分组，各组显示计数，组标题会在该组滚动时固定在顶部。每行有会话标题或第一条提问。下方显示 Agent，Claude Code 会话如果来自 `~/.claude` 以外的目录也会显示该目录，列出所有项目时还会显示所属项目。末尾是最后使用时间。首次读取时会显示列表行的占位形状。**本项目** 显示当前窗口文件夹及其子目录的会话，**所有项目** 显示所有文件夹的会话。搜索框可按标题、首条提问、文件夹、Agent 或 ID 筛选，匹配词会在行中标出。在搜索框按 ↑ 或 ↓ 移动选择，重新读取会话时会继续选中同一个会话。Tab 进入列表，Esc 返回搜索框。随后读到的新会话会淡入。

用 **恢复**、Enter 或双击可在原项目的编辑器聊天中打开会话。可以阅读历史并用同一个 Agent 继续对话，重新打开聊天会保留草稿。**使用其他 Agent 接续…** 可另选一个 Agent。**复制恢复命令** 或列表中的 `⌘C` 会复制 Agent 的终端命令。打开会话时，如果项目文件夹已找不到，会显示提示。

在 FiveLeaf 终端中运行的 Agent 可通过 OSC 7501 报告状态（运行中、等待操作、完成或失败）。状态显示在终端恢复的会话旁。终端没有明确恢复某个会话时，状态显示在同目录中自该 Agent 启动以来写入的最新匹配会话旁。

<a name="quick-open"></a>

## 快速打开

`⌘P`（Windows 和 Linux 为 `Ctrl+P`）打开模糊文件搜索，最近的文件排在最前。在 Git 工作树中只列出已跟踪文件，构建输出不会混入。

- 输入 `:42` 跳到第 42 行。
- 输入 `@` 列出文件的函数、类型和标题。
- 输入 `>` 或按 `⇧⌘P` 可按名称运行命令。各命令显示所属菜单、快捷键和启用状态的对勾，最近运行的命令排在最前。

<a name="find-and-replace"></a>

## 查找和替换

`⌘F` 打开查找，`⌥⌘F` 打开替换，可以选择区分大小写、全词匹配和正则表达式（`$1` 代表捕获组）。较大的文件会在输入时于后台查找匹配项。

<a name="search"></a>

## 搜索

点击 **资源管理器** 旁的放大镜，按 `⇧⌘F`，或使用 **编辑 → 在文件中查找**，可在当前文件夹中搜索快速打开所列的全部文件。支持区分大小写、全词匹配和正则表达式。单行选区会用作搜索词。结果边找到边显示，在各文件标题下按匹配项列出行号和内容。点击文件标题或面板标题中的 **全部折叠** 可以折叠结果。单击或移动到结果时，编辑器会在预览标签页选中并显示匹配项，键盘焦点仍留在结果中。按 Enter 或双击会保留标签页，并将键盘焦点交给它。按 ↓ 从搜索框进入结果，随后用 ↓ 或 ↑ 移动。在首个匹配项按 ↑，或按 Escape，可返回搜索框。搜索进行时，标题下方有移动中的细条。

- 在侧栏顶部选择 **平铺列表** 或 **目录树**。点击文件夹可折叠其中的结果。切换布局时保留搜索词，Git 布局不受影响。
- 有未保存改动的文件会按编辑器当前内容搜索。输入或磁盘发生变化时，结果会随之更新。
- 跳过二进制文件及超过 4 MB 的文件，最多显示 20,000 个匹配项。
- **⋯** 展开 **包含的文件** 和 **排除的文件**。模式以逗号分隔，例如 `*.go, web/**`。`*` 和 `?` 匹配名称内的字符，`**` 匹配任意层级目录，`{ts,tsx}` 匹配其中任一项。`*.ts`、`testdata` 等不带斜杠的模式会匹配任意位置的名称，带斜杠的模式从当前文件夹的根目录匹配。与某文件夹匹配的模式也会匹配其中的文件。

<a name="replace"></a>

### 替换

查询旁的箭头（`⇧⌘H`、**编辑 → 在文件中替换**）可显示替换输入框。各匹配项会加删除线，并在旁边显示替换后的文本。正则表达式中的 `$1` 指捕获组。

- 替换文字旁的 **全部替换** 会先确认，然后替换所有匹配项。
- 文件标题上的按钮替换该文件的所有匹配项，单条匹配旁的按钮只替换该项。
- 在编辑器中打开的文件会把替换记为一步撤销操作。未打开的文件会立即写入磁盘，保留换行符和权限。**全部替换** 会提前提示这部分操作无法撤销。
- 替换时会按最新文本重新查找匹配项。若单条匹配在搜索后改变了位置，会保留该内容并提示重新搜索。

<a name="windows"></a>

## 窗口

每个文件夹默认在独立窗口中打开。

- 标题栏显示项目、工作树和分支。主工作树总是标为 `main`，即使分支使用其他名称。链接的工作树显示其目录名。Git 仓库外的文件夹只显示项目名。
- 点击项目名，可按名称或路径搜索最近的项目。列表下方保留 **打开本地文件夹…** 和 **打开远程文件夹…**。悬停或用键盘选中一行，可选择 **在此窗口中打开**、**在新窗口中打开**、**在 Finder 中显示**（在其他系统上使用本地文件管理器）和 **从最近项目中移除**。
- **在此窗口中打开** 替换当前项目前，会提示确认未保存的更改。目标项目已在另一窗口打开时，其编辑状态会移到这里。目标已经是此窗口的项目标签页时，直接选中该标签页。
- 项目选择器的 **在新窗口中打开** 始终使用独立窗口，即使开启了 **项目标签页**。已打开的项目会带着未保存的变更移出共享窗口。如果项目已有独立窗口，则将该窗口切到前台。
- 从最近项目移除一项时，其文件和已保存会话仍会保留。远程 SSH 项目在列表中保留主机和路径，远程目录的本地文件管理器操作不可用。
- 点击标题栏的工作树或分支可打开对应的 Git 搜索选择器。拉取请求状态仍在底部状态栏显示。
- **打开文件夹…**（`⌘O`）在当前窗口打开文件夹。
- **新建窗口**（`⇧⌘N`）打开一个显示欢迎页的空窗口。
- **在新窗口中打开文件夹…**（`⌥⌘O`），或对最近的文件夹按住 `⌘` 单击（也可按 `⌘↵`），会在新窗口打开。
- **文件 → 打开最近的文件夹…** 列出最近十个文件夹，当前窗口的文件夹和已不在磁盘上的文件夹会跳过。还能 **清除最近打开记录**。在 macOS 上，程序坞图标菜单的 **新建窗口** 下也会列出这些文件夹。
- `⌃R`（或 **打开最近的文件夹… → 更多…**）按名称查找最近的文件夹。`↵` 在当前窗口打开，`⌘↵` 在新窗口打开。终端有键盘焦点时，`⌃R` 由 shell 处理。
- 其他打开文件夹的命令遇到已在窗口中打开的文件夹，会将其窗口切到前台。

<a name="project-tabs"></a>

### 项目标签页

开启 **查看 → 项目标签页** 后，可在同一窗口中打开多个文件夹并切换项目。

- 左侧切换栏为每个项目显示一个方块。当前项目在栏边有一条胶囊形标记，存在未保存更改的项目带圆点。悬浮提示显示项目名、文件夹和切换快捷键。切换栏平时隐藏，指针靠近窗口左边缘时滑出，移开后收回。窗口只有一个项目时也会显示，方块后有打开其他文件夹的按钮。
- 各方块显示项目的 favicon 或标志，没有图标时显示文件夹名缩写。图标可来自常用图标文件（含 `favicon.ico`）、MyGo 应用图标（`mygo.json` 的 `icon` 或 `resources/icon.png`）、源码声明的图标（例如 `site/index.html`、`docs/index.html`），或者 macOS 应用的 `.icns` 或 Xcode AppIcon。通过 SSH 连接的远程项目也一样。
- 缩写为两个字母。若多个项目会得到相同缩写，取第一个有区别的字母来区分，例如 Downloads 和 Documents 显示为 `Dw` 和 `Dc`。远程文件夹的方块角落有服务器标记，主机已连接时为灰色，连接中为琥珀色，未连接时为红色。
- 在方块的上下文菜单选择 **重命名标签…**，可以用最多两个字符（含表情符号）替换缩写或标志，留空时恢复。**标签颜色** 可选择一种终端配色作为方块色调。
- 从 Finder 或资源管理器拖图到方块上，或从右键菜单用 **选择图标…**，可用 PNG、JPEG、WebP、SVG、ICO 或 ICNS 替换项目标志。远程项目也能使用图标，主机断开时仍会显示。FiveLeaf 会在 `settings.json` 旁的 `project-icons` 里保留副本，原图片可以移动或删除。**重置图标** 恢复项目标志。自定义图标和文本标签会相互替换。
- 沿切换栏拖动方块可调整项目顺序，从 Finder 拖入文件夹可添加项目。
- 点击方块会回到项目原来的标签页、分栏、终端、资源管理器和源代码管理，恢复各编辑器的光标与滚动位置。各项目独立保留侧栏当前内容、开关状态和宽度，以及面板高度。新项目沿用当前显示项目的布局。`⇧⌘]` 和 `⇧⌘[`（**转到 → 下一个项目** 与 **上一个项目**）沿栏切换，`⌃⌘1…9`（Windows 和 Linux 为 `Ctrl+Alt+1…9`）按顺序直接选择项目。
- 用 `⌘O`、`⌥⌘O`、最近打开、欢迎页或 `ff <dir>` 打开文件夹时，会将项目加到切换栏，已有项目则切换到它。方块后的 `+` 也可以打开文件夹。
- 方块的上下文菜单可以在 Finder 中显示文件夹、复制路径、重命名、调整颜色或更换图标，也可以关闭本项目或其他项目。
- 可用 **文件 → 关闭项目**、方块上下文菜单，或在没有文档标签页时按 `⌘W` 关闭项目。有未保存的更改时会先确认。关闭窗口会关闭全部项目，下次启动时会按切换栏顺序恢复。
- 离开项目时会自动保存启用了自动保存的文件。终端会继续在后台运行。终端响铃或发送通知（OSC 9 或 777）时，项目方块会用强调色标记，切回项目后清除标记。
- 启用项目标签页会把已打开窗口中的项目集中到最前的窗口。关闭后，各项目会分回独立窗口。

<a name="remote-ssh"></a>

## 远程 SSH

通过 **文件 → 远程 SSH → 连接到主机…**、欢迎页或命令面板，可以用系统自带的 `ssh` 打开另一台机器上的文件夹，远端无需安装 FiveLeaf。当前支持 macOS 和 Linux，Windows 暂不支持。

- 选择器在 **最近** 下列出连接过的主机，显示各自主机上上次打开的文件夹。随后是 `~/.ssh/config` 及其包含的配置中的主机。每项显示 `ssh -G` 解析出的用户和机器。可输入文字筛选，或输入 `user@host` 或 `user@host:port` 连接列表之外的主机。连接时会显示使用的用户，数秒后也会显示已等待的时间。按 Escape 返回主机列表。
- 输入框旁的 **SSH 配置**、**文件 → 远程 SSH → 打开 SSH 配置** 或命令面板可在标签页打开本机的 `~/.ssh/config`，远程窗口中也能用。配置不存在时会创建一个只有所有者可读取的空文件，符合 SSH 的权限要求。配置保存后，下次打开选择器时会从新内容列出主机。若配置是 dotfiles 工具所创建的符号链接，编辑器会打开实际指向的文件，保存时会保留符号链接。
- 连接后，选择器从主机上次打开的文件夹或用户主目录开始列目录。输入路径（`~` 表示用户主目录），用 ↑↓ 选目录，按 `↵` 或 Tab 进入，输入 `..` 返回上一级。在第一行按 `↵` 会打开输入的目录。打开方式与 **打开文件夹** 相同。如果当前窗口为空则在其中打开，否则使用单独的窗口或项目标签页。
- FiveLeaf 使用密钥和 SSH agent 登录，并遵循 `~/.ssh/config` 中的用户、端口、密钥、`ProxyJump` 等配置。应用内无密码登录提示。首次连接尚未信任主机密钥的主机时，请先在终端用 `ssh` 连接一次。每个主机共享一个 SSH ControlMaster 连接，供各窗口和命令使用。关闭该主机的最后一个窗口时结束连接。
- 资源管理器、快速打开、在文件中搜索和替换、源代码管理、行内追溯、边栏标记及差异视图与本地文件夹中的用法相同。`git`、`rg`（或 `grep`）和 `find` 在远端运行，终端也在远端运行 shell。
- 资源管理器读取某一目录时，会在一次往返中一并读取它的子目录，索引跳过的目录（例如 `node_modules`）除外。这样打开子目录无需等待远端。如果目录已在几秒前读取过，会立刻显示缓存，同时再次读取。
- 文件立即打开，读取和保存都在后台进行。保存时先把完整内容送到远端临时文件，全部到达后再写入目标文件，从而保留所有者、权限和链接。传输途中断开时，目标文件会保留原样。保存时同一次往返也会检查远端文件自读取以来有无变化。若已变化，会询问是覆盖还是重新载入远端内容，重新载入支持撤销。
- 和本地一样，会显示远端变更。如果远端装有 `inotifywait`（`inotify-tools` 软件包），由它通知变更。否则每 3 秒检查一次当前显示的目录和已打开文件，窗口在后台时每 15 秒检查一次，切回前台时立即检查。没有 inotify 且远端 `stat` 只提供整秒时间时，同一秒内发生且不改变大小的改动可能无法察觉。
- 状态栏显示 `SSH: host`，断开时为红色。其菜单可以重新连接、断开、打开该主机的另一个文件夹或关闭此连接，标题栏也显示主机名。使用 **断开连接** 会保留窗口、标签页和未保存的更改。重连前文件为只读，并显示重新连接的提示横幅。
- 网络中断或 Mac 休眠导致断开时，应用会同样保留工作区，并自动重连。首次等待 2 秒，之后每次加倍，间隔最多 30 秒。窗口回到前台时会立即重连。横幅显示下次尝试时间，并提供 **立即重新连接**。主机拒绝密钥或其主机密钥尚未受信任时，需要手动发起重试。重连会重新读取文件树、已打开文件和状态。远端终端会保留断开前的输出并标记断开事件，重连后重新启动。在 shell 曾报告所在目录时，会回到该目录，旧输出保留在上方。
- 可以用 `⌘V` 或 **粘贴** 将从 Finder 或另一窗口的资源管理器复制的文件粘贴到远端文件夹，也可从 Finder 将文件拖到资源管理器的文件夹上。文件通过一个 tar 流经 SSH 上传到目标目录旁，全部到达后再以各自名称放入目录。重名时按副本命名。复制资源管理器里的远程文件时，剪贴板存入它在远端的路径。粘贴到同一主机的其他文件夹时在远端复制，粘贴到本地文件夹时下载，粘贴到另一主机时经本机转发。资源管理器菜单的 **上传…** 可将对话框中选中的文件复制到远端文件夹。**下载…** 可将远端文件或目录下载到本机指定目录，默认先显示下载目录。完成后可以直接在文件管理器中显示。状态栏列出传输及进度，点击某项可取消，并清除已经传到的部分。
- 在远端终端中粘贴或拖入 Finder 或本地资源管理器中的文件时，会先把副本上传到远端临时目录，再输入远端路径。剪贴板只有图像（如截图）时，图像会作为独立的 PNG 上传，远端 Claude Code 可像处理粘贴到 Mac 上的截图一样使用它。把远端文件拖到其终端，会直接输入远端路径。
- 可将远端端口转发到本机，例如在本机浏览器打开远端正在开发的网页应用。点击远端终端里指向 `localhost`、`127.0.0.1` 或 `0.0.0.0` 的链接会转发对应端口并打开链接。**文件 → 远程 SSH**、命令面板及状态栏的 `SSH` 菜单都提供 **转发端口…**，可按端口号转发。相同的本地端口空闲时优先使用，否则选择另一个端口。状态栏显示已转发的端口，菜单可在浏览器打开、复制地址或停止转发。连接均经由主机的 SSH 连接，主机重连后转发恢复，关闭该主机的最后一个窗口时结束。
- 远程文件夹不提供 **在 Finder 中显示**。远端没有废纸篓，删除文件会先询问，确认后永久删除。
- 远程文件夹的最近记录、窗口和标签页会像本地文件夹一样保存。上次会话打开的远程文件夹会在应用启动时尝试再次连接。

<a name="the-ff-command"></a>

## `ff` 命令

在 macOS 上，**文件 → 安装 “ff” 命令** 会把 `ff` 装到 `~/.local/bin`（该目录在 `PATH` 中时），否则会装到 `/usr/local/bin`，并需要输入密码。在 Windows 上，`ff.cmd` 安装到 `%LOCALAPPDATA%\FiveLeaf\bin`，此目录会加到用户 `PATH` 中。请在新开的终端中使用。在 Linux 上，`install.sh` 将它装到 `~/.local/bin`，Debian 软件包装到 `/usr/bin`。

此前从 macOS 或 Windows 的文件菜单安装过的 `fiveleaf` 命令仍可使用。启动时，如果 `ff` 这一名称可用，且目录可写，FiveLeaf 会将它装到 `fiveleaf` 旁边。也可选择 **文件 → 安装 “ff” 命令**。通过 Homebrew 或 Linux 软件包安装时，可用 `type -a ff` 查看 shell 最先找到哪个可执行文件。

- `ff .` 打开当前目录，进入新窗口或已打开目录的窗口。启用项目标签页时，可以在新标签页打开。
- `ff <file>` 在包含该文件的文件夹窗口中打开文件。
- `ff -g <file:line[:column]>` 打开文件并将光标放在指定行和列。
- `ff -d <file> <file>` 比较两个文件，按差异布局设置并排或行内显示。
- `ff -n [folder or file]...` 在新窗口中打开所给文件夹或文件。省略参数时打开一个新空窗口。
- `ff -w <file>...` 等到文件关闭才返回，因此可以用 `git config core.editor "ff -w"` 在 FiveLeaf 中编辑提交说明。
- `ff --remote <host:/path>` 打开 SSH 主机上的文件夹。
- `ff run <command>...` 按 `keybindings.json` 使用的命令 ID 依次运行命令，例如 `ff run view.terminal git.pull`。有些命令可以在 `=` 后接参数，代替窗口中的提示输入，例如 `file.openFolder=<folder>`、`file.openFolderWindow=<folder>`、`file.saveAs=<file>`、`go.line=<line[:column]>`、`go.quickOpen=<text>`、`view.selectTheme=<theme>` 和 `remote.forwardPort=<port>`。包含未知命令，或给某命令传了不支持的参数时，本次命令都不会执行。
- `ff commands` 每行列出一个命令，用制表符分隔其 ID、名称、快捷键和参数。
- `ff settings` 每行列出 `settings.json` 的一个设置，用制表符分隔键和值，值为 JSON。
- `ff settings get <key>...` 每行输出一个设置值。
- `ff settings set <key>=<value>...` 修改设置，例如 `ff settings set fontSize=16 theme=claude vim=true`。符合 JSON 格式的值按 JSON 解析，其他值作为原始文本。文本本身也可解析为 JSON 时，需要引号，例如 `theme=""`。
- `ff settings unset <key>...` 恢复为首次启动时的默认值。
- `ff settings set <key>+=<item>` 在列表中添加一项，例如 `ff settings set 'fontFeatures+=calt=0'`。`<key>-=<item>` 移除一项，无需重写整个列表。移除最后一项会清掉列表，添加已存在的项不会形成重复项。
- `ff settings set projectTabStyle.'<folder>'.label=MG` 修改项目切换栏样式的一个字段。只指定 `.<folder>` 可设置整套样式。字段可以是 `label` 或 `color`，留空会移除该字段。文件夹名可以包含点，其路径可相对于当前目录或以 `~` 起始。文件夹名称无需用引号包裹。图标从切换栏的菜单选择，修改样式字段时会保留图标。
- `ff settings --folder ...` 读取或修改当前目录 `.fiveleaf/settings.json` 中允许由文件夹设置的选项，例如 `ff settings --folder set autoSave=false`。从项目子目录运行时，会在向上的目录中找到最近的设置文件，即项目读取的文件。若该文件未设置某选项，`get` 会输出 `null`。
- `settings` 子命令直接修改文件，因此可以在 FiveLeaf 关闭时运行。FiveLeaf 若已打开，会立即重新读取文件并应用变更。遇到未知设置、类型错误、超出范围的数值或不在选项内的值时，会提示允许的格式或取值，保留原设置并以状态码 1 退出。
- `ff plugin <command>` 安装、更新、移除、编写或打包插件，详见 [插件开发](PLUGINS.zh-CN.md)。
- `ff --disable-plugins` 临时关闭随 FiveLeaf 提供的插件以外的插件，直到下次启动。
- `ff --help` 列出选项，`ff --version` 输出版本。

命令作用于路径包含当前运行目录的窗口，找不到时作用于最前面的窗口。`--window <folder>` 指定打开对应文件夹的窗口。除了 `-w`，FiveLeaf 完成所求操作后命令就会返回。应用未运行时，命令会启动它。发生错误时，会输出原因并以状态码 1 退出。遇到未知选项时，状态码为 2。

<a name="deep-links"></a>

## 深度链接

`fiveleaf://file/<path>:<line>:<column>` 在包含该文件的窗口中打开文件并跳到指定行、列，找不到匹配的窗口时用最前面的窗口。`fiveleaf://open?file=<path>&line=<line>&column=<column>` 将路径放进查询参数，打开效果相同。浏览器会对路径中的空格做百分号编码，例如 `%20`。文件名中的 `#`、`?` 或 `%` 可以原样保留。文件不存在时，最前面的窗口会显示提示。

LocatorJS 的 **Custom link** 可用第一种形式。

```
fiveleaf://file/${projectPath}${filePath}:${line}:${column}
```

安装 FiveLeaf 时会注册此链接协议。在 Windows 和 Linux 上，点链接会启动 FiveLeaf，已经运行时会交给现有实例处理。

<a name="appearance-and-persistence"></a>

## 外观和状态恢复

FiveLeaf 内置主题使用圆角侧栏，编辑器、标题栏、标签栏和状态栏的背景相互配合。**查看 → 主题** 可选主题和明暗外观。在 **设置 → 插件** 按名称搜索可安装更多主题。One Dark Pro、黑客帝国、紫金和万圣节主题固定为深色。

黑客帝国主题还原两个世界。侧栏、标签栏、面板和状态栏是现实世界的枪灰色，编辑器和终端用矩阵里的绿色，各类代码用不同绿调区分，注释用枪灰色。全窗口用代码字体，文件图标也是绿色。主要按钮用红色胶囊，选中的行用蓝色，放弃或删除等按钮用哨兵的橙色。窗口有键盘焦点时，两层镜像数字雨在欢迎页背景落下。失去焦点或系统要求减少动态效果时，雨会暂停。红眼白兔取代欢迎页标志并出现在状态栏开头，Git 工作时会跳动。

Claude 模仿 Claude Code 的终端界面，有浅色和深色两种。和黑客帝国主题一样，全窗口用代码字体，背景为暖调的近黑色或米白色。强调色和按钮用 Claude 的橙色，橙色按钮上的标签为深色。选中项用长春花色，错误和删除项用 Claude Code 的玫瑰色，与橙色区分。快速打开等浮层用橙色描边。Git 命令运行时，状态栏显示 Claude Code 的转圈效果：`✻` 在多个图形间旋转，光从命令名称上扫过，并显示已用秒数。运行五秒后偶尔会换成 Claude Code 的提示词，例如 Clauding…。Claude Code 的角色 Clawd 取代欢迎页标志，也坐在状态栏开头。它会眨眼，Git 命令或文件搜索运行时会跳动。数字雨和转圈动画暂停时，它也保持静止。

Qoder 取自 Qoder 的 Forest 主题，采用白色或偏绿灰色搭配森林绿，有浅色和深色两种，并沿用 Qoder 的工作区布局。编辑器和下方的终端放在圆角卡片上，周围的标题栏、侧栏和状态栏是一整块带浅纹理的外壳，彼此之间没有分隔线。拖动侧栏或面板边缘时，只在指针附近亮起。侧栏、源代码管理和终端的英文标题采用句首字母大写，例如 `Explorer`。代码沿用 Qoder 的图表色，关键词为绿，函数为蓝，类型为紫，字符串为琥珀色，数字为玫瑰色。Qoder 的鸭子 Qoduck 和 Clawd 一样取代欢迎页标志，出现在状态栏开头，会眨眼、上下摇晃和跳动。状态栏里的 Qoduck 会随当前操作举起道具：搜索文件时用放大镜，Git 工作时用笔记本电脑，通知出现后的几秒内用扩音器。

Grok Bot 取自 Grok Bot 应用的 Sand 主题。界面为白色或近黑灰色，按钮为近黑或近白，Grok 的蓝色用作强调色。有浅色和深色两种，代码沿用 x.ai 终端的暖色。Grok Bot 的圆头上有两只斜眼，也和 Clawd 一样取代欢迎页标志并出现在状态栏开头。跳动时它会抬眼，偶尔向两侧看。

Cursor 沿用 Cursor Light 和 Cursor Dark。浅色和深色主题分别用近白或近黑灰色，强调色和按钮用 Cursor 的蓝色，代码也沿用 Cursor 的颜色。欢迎页保留 FiveLeaf 标志，这个主题没有独立角色。

紫金主题名为 Porphyry，取意镶在金色马赛克里的帝王紫。编辑器为深紫色，四周用泰尔紫，状态栏也是泰尔紫，文字为金色。强调色、按钮及选中行用金箔色，标题栏下方和状态栏上方有金色细线。当前标签页有一条镀金线，中央点缀一颗宝石。代码使用紫水晶、金色、蔷薇石英和翡翠色。角色 Corona 是一顶嵌有紫水晶和红宝石的金箔王冠，出现在欢迎页及状态栏开头，跳动时宝石会闪光。

南瓜灯主题用烟黑色外框围住暖调编辑器，强调色和按钮用南瓜橙，状态栏像灯笼表面一样发光。代码使用烛黄、余烬色和藤蔓绿，关键词用女巫紫。女巫魔药主题用李子紫外框、女巫紫状态栏和黏液绿按钮及强调色，代码使用深浅紫、黏液绿、青色和淡紫。血月主题为带红底色的近黑界面，按钮和强调色用绯红，状态栏用暗血色，放弃或删除等操作用另一种鲜红色。代码使用红色、旧金色和月光蓝。三个主题分别有用强调色格子绘成的角色，和 Clawd 一样出现在欢迎页及状态栏开头。南瓜灯的刻面会发光，女巫魔药的坩埚会冒泡，血月的蝙蝠会在跳动时扇翅。

**查看 → 主题 → 颜色主题…**（`keybindings.json` 中是 `workbench.action.selectTheme`，例如 `cmd+k cmd+t`）或欢迎页的 **颜色主题…** 会打开主题选择器。列表以小窗口预览各主题的颜色和角色。用 ↑、↓ 移动时，窗口会预览对应主题。←、→ 切换明暗外观。按 Return 确认，按 Escape 恢复打开选择器时的设置。切换主题或外观时，窗口会渐变到新颜色。系统要求减少动态效果时会立即切换。

侧栏按钮默认为左下角，终端按钮默认为右下角。右键单击任一按钮，选 **底部左侧** 或 **底部右侧** 可单独调整它的位置。移动侧栏按钮时侧栏也会移动，终端按钮的位置独立于终端面板。**查看 → 侧边栏位于右侧** 和 **设置 → 外观 → 布局 → 侧边栏位于右侧** 可调整侧栏的位置，同一设置分组中的 **终端按钮在右侧** 调整终端按钮的位置。两项设置对所有窗口生效，重启后仍会保留。

应用会记住侧栏和面板所在边及尺寸，并保存各窗口的目录、窗口位置、分栏和标签页，各标签页的光标、选区、滚动位置和换行状态，以及资源管理器中展开的目录。启动时未指定文件夹，FiveLeaf 会恢复退出时打开的窗口。

**设置 → 外观 → 窗口 → 背景不透明度** 可以在 35% 至 100% 之间调整。较低时可透过磨砂背景看到桌面，文字和控件保持原来的不透明度。该设置作用于编辑器、侧栏、面板和设置窗口，卡片式主题也支持。设为 100% 时，背景完全不透明。系统没有原生背景材质时，背景始终不透明。

自定义主题是 `~/.fiveleaf/themes` 下以主题 ID 命名的 JSON 文件。FiveLeaf 会读取其中的界面颜色、代码及终端配色、字号和布局。**插件 → 打开主题文件夹** 会打开该目录并写入一个示例。插件也可以贡献主题，在 `settings.json` 中用 `themes` 可定义随其他设置存放的主题。详见 [主题](THEMES.md)。

通过关闭窗口、**文件 → 关闭文件夹**，或在所在窗口打开另一个文件夹而关闭的最近文件夹，下次打开时会恢复原来的标签页、分栏和资源管理器状态。关闭最后一个窗口会退出应用。

<a name="plugins"></a>

## 插件

插件是 `~/.fiveleaf/plugins` 下的 JavaScript 或 TypeScript 目录，由 FiveLeaf 自己的引擎独立运行。安装后可直接使用，无需 Node 或构建步骤。插件可添加命令、键盘快捷键、菜单项、状态栏项、侧栏视图、源码旁的预览、格式化器、诊断、主题（含 VS Code 主题）、语言、代码片段和语言服务器。SSH 文件夹也能使用插件，远端无需安装插件本身。详见 [插件开发](PLUGINS.zh-CN.md)。

- `ff plugin install <git-url or owner/repo>` 安装插件。**插件 → 管理插件…** 打开设置窗口的插件页，可安装、更新、移除、启用或停用插件，并更改其设置。
- **插件 → 显示插件日志** 和 **显示运行中的插件** 显示插件记录的日志及正在使用的功能。
- **选择 → 格式化文档**（`⇧⌥F`）优先用格式化插件，其次用支持格式化的语言服务器。可在 **设置 → 插件** 为前端文件启用 Prettier、为 Python 启用 Ruff，或为 C 和 C++ 启用 ClangFormat。Go 和严格 JSON 也有内置格式化器。启用 **保存时格式化** 后，显式保存会进行格式化。
- 插件声明的语言服务器会为问题加下划线，并响应 **转到 → 转到定义**（`F12` 或 `⌘` 单击）、**转到 → 显示悬停信息** 和 **选择 → 补全单词**（`⌃Space`）。
- 在源码编辑器输入两个标识符字符，或输入语言服务器指定的触发字符后，光标旁会显示建议。用 ↑、↓ 选择，Tab 插入，Esc 关闭。Enter 会开始新行。`⌃Space` 打开可搜索的列表。语言服务器没有匹配项时，会建议本文件附近文本的同前缀单词。可在 **设置 → 编辑器 → 代码补全** 切换自动建议。
- **显示问题** 会列出插件找到的全部问题，状态栏显示计数。
- **选择 → 插入代码片段…** 插入由插件提供的代码片段。
- `~/.fiveleaf/scripts` 下 `.ts` 文件的每个导出函数都会成为一条命令。**插件 → 将选中内容作为脚本运行** 会运行当前选区一次。
- 安装 **Word Count** 可在状态栏显示 Markdown 文件的字词数，安装 **TODOs** 可在侧栏查看 TODO 注释。
- 各语言插件覆盖常用前端、后端和配置文件。先安装对应语言服务器，再在 **插件 → 管理插件…** 安装并启用插件。支持的语言、安装命令和 SSH 配置详见 [语言服务器](LANGUAGE-SERVERS.zh-CN.md)。

<a name="settings"></a>

## 设置

**FiveLeaf → 设置…**（`⌘,`），或 Windows 和 Linux 上的 **文件 → 设置…**，会打开设置窗口。设置按类别显示，可以搜索。与默认值不同的项有标记和重置按钮。更改会立即应用到所有窗口，包括代码和终端的字体、字重、连字及行高，还有主题和明暗外观、自动保存、自动换行、差异布局与 Vim 等。

**文件 → 打开设置 (JSON)** 可在标签页打开 `settings.json`，保存后同样立即生效。窗口、标签页、最近打开的文件夹和布局由 FiveLeaf 保存在旁边的 `state.json` 中。每个设置键和文件位置详见 [设置手册](SETTINGS.zh-CN.md)。

文件夹可在 `.fiveleaf/settings.json` 中指定自己的部分设置，例如 `vim` 或 `autoSave`。从设置窗口右上角选择文件夹，或用 **文件 → 打开文件夹设置 (JSON)**。详见 [文件夹设置](SETTINGS.zh-CN.md#folder-settings)。

<a name="keyboard-shortcuts"></a>

## 键盘快捷键

**文件 → 键盘快捷方式…** 在设置窗口列出全部命令和按键。可按名称搜索，也可按下要查找的组合键。点击命令后按下新组合键，并查看还有哪些命令在使用它。每次修改都会立即写到 `keybindings.json`，并保留注释。

**文件 → 打开键盘快捷方式 (JSON)** 打开 VS Code 格式的 `keybindings.json`，可以直接粘贴 VS Code 或 Cursor 的配置。保存后立即应用到所有窗口。单次按键和多键组合都可以绑定到 FiveLeaf 命令或对应的 VS Code 命令名，并可指定 `when` 条件。格式及 Windows、Linux 上不同的键位详见 [快捷键配置](SETTINGS.zh-CN.md#keybindingsjson)。

部分命令只在命令面板中出现，例如 **复制活动文件的路径**、**复制活动文件的相对路径**、**在 Finder 中显示当前文件**（Windows 上为文件资源管理器）、**使用制表符缩进** 和 **用 2、4 或 8 个空格缩进**。**选择 → 按升序排列行** 或 **按降序排列行** 对所选行排序，未选中时处理所有行。**转换为驼峰命名** 处理所选单词，未选中时处理光标处的单词。

<a name="updates"></a>

## 更新

带更新源的发布版本会每小时检查 GitHub Releases，在应用启动或系统唤醒 10 秒后开始检查。有新版本时，左上角的更新图标会亮起。点击图标会打开更新面板，也可从欢迎页或 **FiveLeaf → 检查更新…** 打开（Linux 和 Windows 为 **帮助 → 检查更新…**）。

面板显示发布说明和下载进度。有条件时，FiveLeaf 仅下载变更的部分。应用会验证更新签名，重启后运行新版本。重启仍按照平时的流程处理未保存改动。如果 GitHub 更新失败，可以重试、再次检查，或从发布者的发行页下载安装包。开发版本和由系统管理的安装会用各自的构建或安装方式更新。

发布者设置最低版本后，如果 FiveLeaf 找到了符合要求的更新，更新面板会暂时替代工作区，直到安装后重启，或发布者放宽版本限制。仍可保存已打开的文件并退出。一次成功检查后要求开始生效，在当前运行会话中即使连接短暂中断，也会继续生效。若最低版本上调前已经下载了更新，请重启以继续更新。发布者的配置详见 [发布流程](../CONTRIBUTING.zh-CN.md#require-a-minimum-version)。
